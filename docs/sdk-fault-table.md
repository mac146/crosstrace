Notes (checked in the SDK source, not inferred from the table):
- `stream_stall`: openai-python and anthropic-python default to a 600 s read timeout (`DEFAULT_TIMEOUT` in `_constants.py`), so a stalled stream holds an agent for up to 10 minutes per attempt.
- `rate_limit_long`: anthropic-python's `_calculate_retry_timeout` sleeps for whatever `Retry-After` says ("just do what it says", capped only at about 49 days); openai-python honours it only up to 2 minutes. A HANG here means the SDK is sleeping as told.
- `stream_cut_clean` (a correctly terminated chunked body without the completion event) is what a gateway or proxy produces when its upstream dies but it ends the response cleanly; the finish/stop reason is missing, which callers can check but these SDKs do not.
- Tool-call rows: the healthy arguments are `customer_id`, `action`, `amount`, `note`; SILENT rows returned a tool call with fields missing and no error or invalid-call marker.
