Your agent said it worked. It didn't.

CrossTrace is a crash test for AI agents. It replays real runs of your agent and breaks one model call at a time, the way providers and networks really break, then tells you exactly what your agent did next. In CI, on every pull request.

How it works

A proxy that breaks things on purpose

CrossTrace sits between your agent and the model provider. Your agent only reads its base URL from the environment, so your real SDK code runs exactly as in production.

Your agent
unchanged code

01 · Record

Capture real runs, once

Run your agent for real, once per input. Every request and the provider's exact response bytes are saved. API keys and headers never are.

02 · Replay

Offline, at $0

The run must replay exactly before any fault, or CrossTrace names the field to mask.

03 · Break

One call at a time

Cut streams, stalls, resets, 429s, overloads. Byte-level, at every call of every path.

04 · Judge

Verdicts from the agent's next move

Did it retry, stop with an error, or carry on as if nothing happened? No AI judge and no comparing free text, so the same trial gives the same verdict every time.

Get started

Four commands. Then it runs on every PR.

Commit the recordings and CI replays them without API keys. The report lands in the job summary, with the fix for your SDK.

terminal
$ pip install git+https://github.com/mac146/crosstrace
$ crosstrace init --command "python agent.py {input}"
$ crosstrace record   # real run, once
$ crosstrace test     # offline, with faults
.github/workflows/crosstrace.yml
on: [pull_request]
jobs:
  resilience:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: mac146/crosstrace@main
        with:
          install: pip install -r requirements.txt
